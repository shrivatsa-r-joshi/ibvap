# Demo Script — draft

Owner: PPT / Script / QA. Fill this in as the live pieces come together; rehearse it out loud, timed.

## Target length
~3–4 minutes live demo, inside a larger pitch.

## Beats

1. **The gap (10s)** — "Border CCTV records, but someone still has to watch every screen. IBVAP makes
   the cameras themselves intelligent — no new hardware."
2. **Show the dashboard (10s)** — live video panel, alerts feed, roadmap cards visible.
3. **Trigger detection (30–40s)** — person/vehicle walks into frame → box appears live with class +
   confidence. Narrate: "This is YOLOv8 running in real time on a completely standard camera feed."
4. **Trigger the fence crossing (30–40s)** — object crosses the virtual line → alert appears in the
   feed instantly, SMS/email fires (show phone/inbox if possible). Narrate: "The moment someone crosses
   a restricted boundary, the system alerts the control room — no human had to be watching."
5. **Roadmap cards (15s)** — "ANPR, face recognition, and night-mode detection plug into the exact same
   pipeline — this demo focuses on the detection-to-alert loop because that's the core value."
6. **Close (10s)** — cost/deployment pitch: retrofits existing cameras, no proprietary hardware, scales
   across remote posts.

## Fallback plan (say this out loud in rehearsal, not just write it down)

- Backup demo video recorded and ready to play if live inference lags or the venue wifi/lighting causes
  issues.
- Know who presses play on the backup and how fast you can switch to it without breaking narration.

## Likely judge questions to rehearse

- What happens with poor lighting / night conditions?
- How do you handle false positives?
- What does this cost vs. dedicated FRS/ANPR hardware?
- How would this work with no/limited internet at a remote BOP?
- How does this scale to many camera feeds at once?
